THE DARKNESS BELOW - AI USE LOG
Jamie Jones and Joe Buckley - Game Jam 2026

This log records where AI tools were used to help make the game.
All AI-written code was added to the project by Jamie, tested in Unity,
and kept or changed based on that testing. Check and add anything missing.

---------------------------------------------------------------

---------------------------------------------------------------
